### Prepare the build 
(default to release use -CMAKE_BUILD_TYPE=Debug for debug)
```sh
mkdir build
cd build
cmake ..
```

### Compile
```sh
make -j
```

### Run
```sh
./TowerDefense
```
Or with the path to a map file
```sh
./TowerDefense ../src/Ressources/map1.txt
```
